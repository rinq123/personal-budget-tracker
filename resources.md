## Setup Approach

Do not install every library before understanding the project shape.

Start by making sure the core tools are available:

- Node.js and npm
- Git
- Docker Desktop
- A code editor
- A GitHub account

Then install project dependencies in stages:

- Stage 1: frontend basics with React, TypeScript, CSS, and React Router
- Stage 2: backend basics with Express and TypeScript
- Stage 3: local database with PostgreSQL through Docker Compose
- Stage 4: Prisma for schema, migrations, and database access
- Stage 5: authentication and validation libraries
- Stage 6: testing with Vitest and Supertest
- Stage 7: GitHub Actions
- Stage 8: Azure and Supabase deployment configuration

This keeps each tool connected to a concrete problem instead of turning setup into a large dependency list with no context.
